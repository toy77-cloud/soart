Notification keys

These two keys let your GitHub job send notifications to your phone. They're created right here in your browser and never sent anywhere. Generate them once.

Public key

Paste into firebase-config.js as VAPID_PUBLIC_KEY, and into a GitHub secret named VAPID_PUBLIC.

Private key: keep secret

Paste ONLY into a GitHub secret named VAPID_PRIVATE. Never put it in a file in your repo.
